# FootageCrate runtime plates

User-supplied downloads converted for the browser on 2026-07-26.

| Runtime file | Source download | Use |
| --- | --- | --- |
| `atmospheric-fog-23.mp4` | `FootageCrate-Low_Atmospheric_Fog_23-LQ.mp4` | Full-frame fog atmosphere |
| `atmospheric-fog-23-alpha.webm` | derived from `FootageCrate-Low_Atmospheric_Fog_23-LQ.mp4` | Nebulus fog with the near-black background keyed to real alpha |
| `simple-explosion-30.webm` | `FootageCrate-Simple_Explosion_30-LQ.mov` | Lotus detonation |
| `fireball-1.webm` | `FootageCrate-Fireball_1-LQ.mov` | Energy Orb core |
| `fire-track-right.webm` | `FootageCrate-Fire_Track_Right-LQ.mov` | Directed fire trail |

The three MOV sources were converted from ProRes 4444 to VP9 WebM with alpha.
The fog source was converted both to a 30 FPS H.264 MP4 and to a VP9 WebM
whose near-black background is keyed to alpha. The two-spell runtime uses the
alpha WebM so the live camera is not covered by a dark rectangle. Audio was
removed.
